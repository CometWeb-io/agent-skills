# Style-pattern false positives

Catalog entries are editing prompts, not authorship evidence or a banned-word list. No benchmark or detector performance is established by the bundled catalogs.

- Ordinary grammar such as “nie tylko X, ale także Y” / “not only X, but also Y” is valid. Edit empty escalation or harmful repetition, not the conjunction itself.
- Domain terms such as “słowa kluczowe” and repeated API names can be the precise wording. Keep them instead of forced synonyms.
- One “Summary” / “Podsumowanie” heading can be useful navigation. A generic skeleton merits revision only if more specific labels help the reader.
- Formal transitions, restrained language, punctuation and hedges can carry the intended register or uncertainty. Preserve that meaning even when a catalog flags the surface form.

A pattern count does not establish AI authorship. Check whether the alleged defect actually harms this text before changing it.
