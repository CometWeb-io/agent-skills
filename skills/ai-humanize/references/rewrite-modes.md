# Rewrite depth

Use the user's requested scope. When naturalness is the goal, retain wording that already works; changed phrasing is not itself an improvement.

- `light`: local edits, preserving structure and intentional voice. Default for sensitive normative/scientific wording unless stronger rewriting is requested.
- `strong`: change sentences and paragraph boundaries while retaining the argument and evidence. Do not turn a request to humanize into new copywriting or strategy.
- `deep`: substantial recomposition only when requested. For dense claims, read `references/semantic-fidelity.md` and map the propositions before restructuring. Preserve procedural order, causal chains, conditions, quotes and code where order or exact wording matters.

No distance quota, compulsory structure change, repeated second rewrite, synonym pass or sentence-length recipe. Stop when the requested expression is clear and faithful. If a style sample is needed, use `references/voice-and-register.md`; it supplies voice rather than facts.

Provenance questions are a separate operation under `references/provider-routing.md`, not a reason to deepen every edit or promise detector defeat. Deliver the edited text; add an audit only when requested or materially relevant.
