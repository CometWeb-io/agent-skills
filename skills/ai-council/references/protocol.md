# Council protocol v5

## Kolejność

1. Decision Contract + explicit `as_of`.
2. Internal Context Router dla materialnych internal claims.
3. Planner: mode, budget, role classes, frameworks, evidence areas, temporal requirements.
4. Base-rate / outside view, gdy archetyp ma sensowne analogie.
5. Private knowledge routing per role.
6. Blind advisers/specialists.
7. Assumption Ledger.
8. Post-blind Decision Memory + calibration/analogies.
9. Rebuttals + double-crux.
10. Live Evidence + claim-specific Source Authority.
11. Temporal Truth + Freshness Gate.
12. Evidence Coverage + Contradiction Coverage.
13. Premortem, jeśli wymagany.
14. Risk gates.
15. Correlation-adjusted consensus + Independence Grades.
16. Minority Sentinel.
17. Red Team.
18. Evidence Judge.
19. Counterfactual/no-action/timing review.
20. Value of Information + deliberation stop.
21. Forecasts dla DEEP/high-stakes, jeśli rozstrzygalne.
22. Confidence decomposition.
23. Chairman proposal.
24. Constraint/Freshness/Human Approval gate.
25. Experiment dla TEST.
26. Immutable Snapshot v3+ temporal metadata.
27. Living Decision Validity Overlay + Watch Dependencies.
28. Output.
29. Transactional write-back.

## Blind firewall

Blind participant nie może dostać peer memo, konsensusu, historical outcomes, calibration, consensus-failure patterns, Red Team output ani preferencji Chairmana.

Blind memo: vote, confidence, thesis, claims `[F] [A] [I] [FMW] [O]`, assumptions, risks, strongest falsifier, what changes my mind, evidence needed.

## Anti-groupthink

Mierz raw i adjusted consensus. Wspólny model/framework/source nie jest niezależnym potwierdzeniem. Minority Sentinel chroni materialny independent dissent, ale dissent sam w sobie nie daje punktów.

## Anti-overthinking

Po dodatkowej rundzie oceniaj marginal information gain. Zatrzymaj przy saturation/ujemnym VOI, chyba że unresolved mandatory gate/freshness blocker wymaga rozstrzygnięcia.
