# Council workflow — DEEP

For high lock-in, regulation, multi-system, or expensive-to-reverse decisions. Includes full STANDARD path plus:

1. Complete STANDARD steps 1–29 (`workflow-standard.md`).
2. 1–5 resolvable forecasts when valuable (`forecasting.md`); score later via `forecast-score`.
3. `portfolio` when the decision competes for shared capacity (`portfolio.md`).
4. Decision Validity Overlay + Watch Dependencies (`living-decisions.md`).
5. Champion/challenger / `eval-compare` when improving Council itself.
6. Process Memory write when freshness, routing, watch, gate, minority, Chairman, or escalation produced a material lesson.
7. Decision Memory lifecycle `Writing → Complete` as final record.

Never load DEEP by default for LIGHT asks. Prefer STANDARD unless downside/lock-in justifies cost.
