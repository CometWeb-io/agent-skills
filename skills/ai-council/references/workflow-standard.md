# Council workflow — STANDARD

Default for material decisions.

1. Set `as_of`. Build Decision Contract (`decision-contract.md`).
2. `context-route` for material internal claims (`internal-context.md`).
3. `plan` → STANDARD budget, roles, frameworks, critical evidence areas (`modes.md`).
4. Optional `base-rate` without showing historical verdicts to blind experts.
5. Private knowledge via `knowledge-routing.md` / `capability-packs.md`.
6. Blind round; do not read Decision Memory until all blind memos finish.
7. Memo fields: vote, confidence, thesis, claims, assumptions, risks, strongest falsifier, what changes my mind, evidence needed, provenance lane.
8. Assumption Ledger (`assumptions.md`).
9. Read Decision Memory; limited analogies; calibrate on settled decisions with sample strength.
10. Rebuttals + `crux` (falsifiable).
11. `source-authority` per material claim (`source-authority.md`).
12. Live evidence within budget.
13. `temporal` + `freshness` (`freshness.md`).
14. `coverage` + `contradiction`; critical unresolved contradiction blocks readiness.
15. Premortem when required.
16. Gatekeepers (`legal-risk.md` and risk surface).
17. `consensus` + `independence-grade` (I0–I4).
18. `minority` — preserve material independent dissent.
19. Red Team + Evidence Judge (Chairman sees only accepted + temporally admissible evidence).
20. Counterfactual / best-alternative / no-action / timing as mode requires.
21. `voi` / `stop` when additional research has cost.
22. Confidence decomposition.
23. Chairman proposes `GO | NO-GO | TEST | DEFER`.
24. Required Confidence + `gate`; `BLOCK` cannot be voted down; `COUNSEL_REQUIRED` → DEFER.
25. Human escalation packet if needed (`human-escalation.md`).
26. Experiment Spec for `TEST` (`experiments.md`).
27. `tool-authority` before side effects (`tool-authority.md`).
28. Immutable Decision Snapshot + hash.
29. Format via `output-contract.md`.

Skip forecasting / portfolio / living-decision overlay unless risk surface or user forces DEEP.
