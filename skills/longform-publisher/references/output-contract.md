# Output contract

When the user asks for the actual ebook/report/playbook/guide, return the finished manuscript or requested artifact as the primary deliverable. A control brief must not replace the publication.

For readiness/status/refresh planning, default to:

```text
Stan
PUBLICATION SUMMARY
CURRENT STAGE
BLOCKER
VERIFY NOW
DECISION NOW
NOW
NEXT MILESTONE
DELEGATE
WAITING
STOP
```

Omit empty lanes. Keep one action per bullet and keep `Done` conditions observable.

The deterministic `render-manifest` output is a control-plane projection, not the manuscript itself.

When a file artifact is requested, follow the corresponding specialist skill's creation and visual QA requirements before marking it ready.
