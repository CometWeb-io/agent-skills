# Specialist delegation

Longform Publisher owns publication state, canonical manuscript lineage, claim-use reconciliation, editorial gates and release readiness. Delegate deep specialist work.

| Need | Skill | Return contract |
| --- | --- | --- |
| consequential/current/disputed research | `evidence-researcher` | admitted evidence/claim status with freshness and gaps |
| scientific study/manuscript/submission readiness | `research-program-operator` | current research-program gate/readiness and unresolved governance/evidence requirements |
| prose naturalization or substantial rewrite | `ai-humanize` | revised text preserving source meaning; must re-enter fidelity gate |
| marketing landing/page conversion copy | `copywriting` | conversion copy; factual claims still subject to source policy |
| DOCX generation/editing | `docx` | final DOCX plus required render/visual QA status |
| PDF generation/editing/inspection | `pdfs` | final PDF plus required render/visual QA status |
| graphics/illustrations | `image` | requested visual asset with provenance/usage constraints as relevant |
| content portfolio/topic planning | `content-strategy` | prioritized content decision/input, not manuscript truth |

Do not delegate merely because a skill exists. Use the specialist only when its domain gate is material to the current publication stage.
