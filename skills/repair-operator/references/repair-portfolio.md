# Repair portfolio

For campaign/portfolio repair planning, classify each repair by `effort_band` (XS/S/M/L/XL), `blast_radius` (LOCAL/SECTION/CROSS_ARTIFACT/SYSTEM), and `reversibility` (EASY/MODERATE/HARD/IRREVERSIBLE). An irreversible change requires an explicit approval gate. Effort units support capacity planning; they do not override blockers or dependencies.
