# Evaluation

Golden invariants:

1. DEEP cannot pass without the complete deep-check set.
2. Broken local references cannot pass.
3. A package with no executable behavior cases cannot pass.
4. Material unknown checks produce DEFER.
5. BLOCKER/MAJOR check failures need evidence.
6. Host runtime claims not backed by runtime verification are surfaced.
7. Generated junk/symlinks in a portable package are material defects.
8. A skill over 500 SKILL.md lines is surfaced as a progressive-disclosure defect.
9. DELTA requires a distinct baseline version.
10. Static audit never claims model lift.
