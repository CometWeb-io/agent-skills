# Behaviour evaluation — not pre-executed model results

Run every case in a clean supported host with the actual package loaded and realistic
capabilities/fixtures. Record model/host/version/date, input assets, tool transcript,
resulting artifacts, expected mode, omissions, unsupported assertions, and reviewer.
Check each must/must_not condition against observable output and tool use. Any fabricated
source, false test pass, unauthorized publication, or invented installation fails the case.

The JSON cases are inputs and acceptance criteria, not proof of passing behaviour.
Unit tests only check that this suite is well formed. At initial package creation,
model/host executions and independent reviews are not claimed. Add one real CometWeb
volume acceptance run after approved logo/font/reference files and source evidence are
available. Inspect the complete publication, not merely metadata or the cover.
