# Quality Loop Operator 1.8.0

Coordinate candidate-bound review, repair and verification when a task needs resumable quality state. Start with one relevant review; add another only for a distinct question or explicit requirement. Existing artifacts need no automatic brief/writer cycle.

Ordinary work uses SKILL.md and a short result. Formal sidecars can declare a prelocked `required_stages` plan; old sidecars retain their full profile sequence. The kernel validates declared identity and gate consistency, not the truth of findings or whether checks ran.

Keep static package checks, model behavior, live-host support and publication authorization separate. This skill does not replace general orchestration, specialist analysis or software release readiness.
