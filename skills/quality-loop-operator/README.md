# Quality Loop Operator 1.4.0

Domain control plane for the CometWeb Quality Skills family. v1.4 adds adaptive depth, exact-fingerprint stage reuse, deterministic replay checks, quality-debt blocking, and a SKILL_QUALITY lane that keeps static skill audit separate from empirical skill evaluation.

It does **not** replace general `skill-orchestrator`, `ai-council`, `skill-creator`, or software `release-readiness`.
