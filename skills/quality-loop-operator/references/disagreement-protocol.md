# Finding disagreement protocol

Reviewer and roaster findings can overlap without being identical.

Classify each reconciled group:

- `CONSENSUS`: same substantive failure and same severity/blocking effect.
- `NEAR_CONSENSUS`: same failure, adjacent severity or bounded scope difference.
- `CONFLICT`: incompatible severity, scope, evidence interpretation, or blocking effect.
- `UNIQUE`: only one specialist found it; this is not automatically weak.

Never auto-resolve `CONFLICT` by majority, average, or maximum severity. Resolve with a targeted verification question, stronger evidence lane, clearer policy criterion, reproduction, or explicit scope distinction. Preserve the original findings unchanged and emit a reconciliation record.
